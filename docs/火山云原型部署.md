## 3. Nginx 要点

- 监听 `80`，`root /var/www/ailab`
- `index`：`index.html` → `chart-gallery.html`
- `/ailab`、`/ailab/` 前缀 301 到去掉前缀后的路径
- 未配置 HTTPS（443 未开放）

修改配置后：

```bash
sudo nginx -t && sudo systemctl reload nginx
```

## 4. 从本地更新部署

在仓库根目录执行（需本机已装 `rsync`、`sshpass` 或已配置 SSH 密钥）：

```bash
# 推荐：SSH 密钥登录后
rsync -az --delete \
  --exclude '.DS_Store' \
  --exclude '.workbuddy' \
  --exclude '*.bak*' \
  --exclude 'static-html' \
  ./chart-gallery.html ./chart-builder.html ./data-source.html \
  ./indicator-center.html ./manual-data.html ./add-indicator-dialog.html \
  ./drafts.html ./icons.js \
  ./g2.min.js ./exceljs.min.js ./jszip.min.js \
  ./highcharts.js ./highstock.js ./series-label.js \
  ./assets ./docs \
  root@115.191.3.157:/var/www/ailab/

ssh root@115.191.3.157 'chown -R www-data:www-data /var/www/ailab && nginx -t && systemctl reload nginx'
```

入口页 `index.html` 在服务器上单独生成（跳转到图库），`rsync --delete` **不会**删掉它（本地没有同名覆盖文件时需注意：若本地新增 `index.html` 会覆盖线上）。更新后建议抽查：

```bash
curl -sI http://115.191.3.157/data-source.html
```

期望 `HTTP/1.1 200`。
